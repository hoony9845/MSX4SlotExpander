# MSX Expander v2 – 버퍼 + 50핀 IDC 연장, 6슬롯(서브슬롯 4 + I/O 전용 2)

기존 Simple 4Slot Expander(v1)를 다음과 같이 개량한다.

1. **버스 버퍼 추가**: 74HCT541 ×4(주소/제어), 74HCT245 ×1(데이터). 호스트가 보는 부하는 신호당 1개뿐이다.
2. **본체에 직접 꽂지 않음**: 2-보드 구성
   - **어댑터**: MSX 카트리지 슬롯에 꽂는 카드엣지 → 50핀 IDC 헤더 (수동, 1:1 결선)
   - **확장 보드**: 50핀 IDC 입력 → 버퍼 → CPLD(서브슬롯) → 슬롯 6개
     (슬롯 0–3: 확장 서브슬롯, 슬롯 4–5: I/O 전용. 케이블에서 먼 쪽 2개)
3. **연장 케이블**: 2.54mm 50심 플랫 케이블 (IDE 케이블과 같은 형태의 50핀 = SCSI-1 타입)
4. **핀 배열**: 대우 MSX 후면 확장 슬롯(CPC-200/300/400, DPC-200 등)과 동일.
   대우 기종은 어댑터 없이 케이블로 확장 보드에 바로 연결할 수 있다.

> 40핀 IDE 케이블로는 MSX 슬롯 50개 신호를 모두 전달할 수 없다. 그래서 50핀 플랫 케이블을 쓴다.

```
 [MSX 본체 카트리지 슬롯]                [대우 MSX 후면 50핀 헤더]
          │                                      │
   ┌──────┴──────┐                               │
   │ 어댑터 보드 │ 카드엣지 → IDC50 (1:1)        │
   └──────┬──────┘                               │
          └────── 50심 플랫 케이블 (≤30cm) ──────┘ (둘 중 하나)
                         │
 ┌───────────────────────┴───────────────────────────────────────┐
 │ 확장 보드  J1 IDC50                                            │
 │   A0-15, RD WR MREQ IORQ M1 RFSH RESET CLOCK, CS1 CS2 CS12 SLTSL│
 │        └─ U1-U4 74HCT541 ──→ 슬롯측 버스 ──┬─ J4-J7 SLOT0-3   │
 │                                            ├─ J8-J9 SLOT4-5   │
 │   D0-7 ─ U5 74HCT245 (DIR=DATA_DIR) ──────┤                   │
 │   BUSDIR ← R1 ← DATA_DIR ┐                 └─ U7 XC9536XL     │
 │                          └──── U7 ←─ U6 74HCT21 ← 슬롯 BUSDIR │
 │   WAIT, INT : 버퍼 없이 직결 (오픈컬렉터 wired-OR)             │
 │   SOUNDIN   : 슬롯별 점퍼(헤더) JP1-4, JP6-7 경유 직결         │
 │   +5V       : JP5 로 본체(INT) / DC잭+릴레이(EXT) 선택          │
 └────────────────────────────────────────────────────────────────┘
```

## 1. 50핀 IDC 핀 배열 (대우 후면 슬롯 호환)

IDC 헤더 핀 번호 N = MSX 카트리지 슬롯 핀 번호 N (1:1). 예: +5V = IDC 45, 47 / GND = IDC 41, 43.
2×25 박스헤더에서 홀수 핀(1,3,…,49)은 한 줄에, 짝수 핀(2,4,…,50)은 반대 줄에 온다.
결선 규칙은 `gen_schematics.py`의 `idc_pin()` 한 곳에서 정의하며 어댑터 J2와 확장 보드 J1에 같이 적용한다.
(`IDC_ROW_MIRROR = True`로 바꾸면 홀/짝 줄이 바뀐 배열(+5V = IDC 46, 48)로 다시 생성된다.)

| 핀 | 신호 | 핀 | 신호 |
|---:|---|---:|---|
| 1 | /CS1 | 2 | /CS2 |
| 3 | /CS12 | 4 | /SLTSL |
| 5 | (RSV) | 6 | /RFSH |
| 7 | /WAIT | 8 | /INT |
| 9 | /M1 | 10 | /BUSDIR |
| 11 | /IORQ | 12 | /MERQ |
| 13 | /WR | 14 | /RD |
| 15 | /RESET | 16 | (RSV) |
| 17 | A9 | 18 | A15 |
| 19 | A11 | 20 | A10 |
| 21 | A7 | 22 | A6 |
| 23 | A12 | 24 | A8 |
| 25 | A14 | 26 | A13 |
| 27 | A1 | 28 | A0 |
| 29 | A3 | 30 | A2 |
| 31 | A5 | 32 | A4 |
| 33 | D1 | 34 | D0 |
| 35 | D3 | 36 | D2 |
| 37 | D5 | 38 | D4 |
| 39 | D7 | 40 | D6 |
| 41 | GND | 42 | CLOCK |
| 43 | GND | 44 | SW1 |
| 45 | +5V | 46 | SW2 |
| 47 | +5V | 48 | +12V |
| 49 | SOUNDIN | 50 | -12V |

MSX Wiki *Expansion bus slots (50-pin IDC)* 기준으로 대우 기종(CPC-88, CPC-200, CPC-300(E), CPC-330K,
CPC-400(S), DPC-100/180/200(S))은 모두 **"Odd"** 배열이다. 일반 카트리지 슬롯과 비교하면
홀수/짝수 줄이 키(극성 홈) 쪽 기준으로 뒤바뀌어 있다.

### ⚠ 제작 전 반드시 실측할 것
이 설계는 위 표(IDC 핀 N = 카트리지 핀 N)를 전제로 한다.
대우 후면 커넥터는 키가 2개인 형식이라 일반 1-키 소켓은 키 돌기를 깎아야 들어가고, 거꾸로도 꽂힐 수 있다.
그래서 방향을 실물로 확인한다.

1. 케이블 소켓(▲ = 1번 핀)을 대우 본체 후면에 꽂고 전원을 켠 뒤, 반대쪽 소켓에서 GND 기준 전압을 잰다.
2. 판정 (N = 소켓 표기 핀 번호)
   - 45, 47번 = +5V, 48번 = +12V, 50번 = -12V → **정상**(위 표). 확장 보드 J1에 그대로 연결하면 된다.
   - 6, 4번 = +5V (51−N 위치) → 소켓을 **거꾸로 꽂은 것**(180° 회전)이다. 반대로 꽂는다.
   - 46, 48번 = +5V (홀/짝 줄이 바뀜) → **미러 배열**이다. 회전으로는 맞출 수 없으므로
     `IDC_ROW_MIRROR = True`로 바꿔 어댑터/확장 보드를 다시 생성해야 한다.
3. 정상 방향이 확인되면 본체와 케이블에 1번 핀 표시를 해서 역삽입을 막는다.

케이블은 양 끝 IDC 소켓을 같은 방향으로 압착한 일반 플랫 케이블(1번→1번)을 쓴다.

## 2. 버퍼와 방향 제어

| 블록 | 부품 | 방향 | 신호 |
|---|---|---|---|
| U1 | 74HCT541 | 호스트→슬롯 | A3 A0 A1 A13 A14 A8 A12 A6 (슬롯 핀 29–22) |
| U2 | 74HCT541 | 호스트→슬롯 | CLOCK A4 A5 A2 (나머지 4입력은 GND) |
| U3 | 74HCT541 | 호스트→슬롯 | A7 A10 A11 A15 A9 /RESET /RD /WR (슬롯 핀 21–13) |
| U4 | 74HCT541 | 호스트→슬롯 | /MREQ /IORQ /M1 /RFSH /SLTSL /CS12 /CS2 /CS1 (슬롯 핀 12–1) |
| U5 | 74HCT245 | 양방향 | D6 D7 D4 D5 D2 D3 D0 D1 (A측=호스트, B측=슬롯) |
| U6 | 74HCT21 | – | 게이트1: 슬롯 0–3 /BUSDIR의 AND, 게이트2: 게이트1 · 슬롯 4 · 슬롯 5 → /BUSDIR_IN |
| – | 직결 | 슬롯→호스트 | /WAIT, /INT (오픈컬렉터, 호스트 풀업 사용) |

- 버퍼 채널 순서는 PCB에서 슬롯 핀 줄 순서(위→아래)와 같게 정했다. J1 → 버퍼 → 슬롯 버스 배선이 거의 교차하지 않는다.
- 541/245의 /OE는 항상 GND이다. 버퍼는 항상 동작하고 245는 방향만 바뀐다.
- **DATA_DIR** (CPLD 출력, 245의 DIR):

  ```
  DATA_DIR = /RD | (/SLTSL & /BUSDIR_IN)
           = 0 (슬롯→호스트) : 이 1차 슬롯의 메모리 읽기  또는
                               I/O 읽기 중 카트리지가 /BUSDIR 을 내린 경우
           = 1 (호스트→슬롯) : 그 외 전부
  ```
- 호스트 /BUSDIR(J1-10)은 R1(100Ω)을 거쳐 DATA_DIR로 구동한다. 확장 보드가 호스트 버스를 구동할 때 L이 된다.
  v1(`/RD | /SLTSL` 과 카트리지 BUSDIR의 AND)과 같은 동작이다.
- 슬롯측 D0–D7은 4.7kΩ(RN1, RN2)으로 풀업한다. 빈 서브슬롯을 읽으면 FFh가 나온다.
- 슬롯 /BUSDIR은 10kΩ(RN4), 서브슬롯 /SLTSL은 4.7kΩ(RN3)으로 풀업한다. SW1–4로 슬롯을 분리하면 H가 된다.
- **슬롯 4, 5 (I/O 전용)**: /SLTSL을 10kΩ(RN5)로 H에 고정한다. 메모리(ROM/RAM)는 보이지 않고, I/O 포트만 응답한다.
  /BUSDIR(RN5 풀업)은 U6 게이트2로 들어가므로, 이 슬롯의 I/O 읽기에서도 245 방향이 바뀌고 호스트 /BUSDIR이 L이 된다.
  /CS1, /CS2, /CS12 등 나머지 버스 신호는 다른 슬롯과 같이 연결된다(카트리지는 /SLTSL과 조합해 쓰므로 반응하지 않는다).

### 타이밍
- 74HCT541/245 tpd는 5V에서 최대 약 25–30ns이다. 읽기 경로 지연은 주소 버퍼 + 데이터 버퍼로 약 60ns 늘어난다.
  Z80 3.58MHz에서 /RD→데이터 셋업 여유는 수백 ns라서 문제없다.
- 더 빠른 동작이 필요하면 74AHCT541/245를 쓴다(핀 호환). 대신 엣지가 빨라져 링잉이 커지므로 CLOCK, /RD, /WR 출력에 33Ω 직렬저항을 권장한다.
- 50심 플랫 케이블은 GND가 41, 43번 2개뿐이라 리턴 경로가 약하다. **케이블은 30cm 이하**로 쓴다.
  CLOCK(42)은 GND 사이에 끼어 있어 비교적 유리하다.

## 3. CPLD (CPLD_v2/)

`CPLD_v2/EXT_SLT_BUF.v`, `EXT_SLT_BUF.ucf`, `EXTSLT4_BUF.xise` (ISE 14.7, XC9536XL-10VQ44C)

v1과 달라진 점
- CPLD를 **버퍼 뒤(슬롯측)** 에 둔다. FFFFh 서브슬롯 레지스터를 읽을 때는 CPLD가 슬롯측 버스를 구동하고, DATA_DIR=0이므로 245를 통해 호스트로 나간다.
- I/O 핀 34개를 모두 쓰기 위해 **CLOCK 입력을 없앴다.** 레지스터는 /WR 하강엣지(P1 = GCK3)에서 래치한다.
  Z80 메모리 쓰기에서는 /WR이 내려가기 전에 주소, /SLTSL, 데이터가 이미 안정되어 있다.
- **핀 배치를 PCB에 맞춰 새로 정했다** (`EXT_SLT_BUF.ucf`는 `gen_schematics.py`의 `CPLD_PINS`에서 생성된다).
  슬롯 버스가 줄 순서대로 CPLD 왼쪽에서 들어오므로, U7을 180° 돌려 P12–P44가 위·왼쪽·아래 변을 따라 같은 순서로 놓이게 했다.
  /WR은 P1(GCK3) 그대로이고, JTAG(P9/10/11/24)과 전원 핀은 패키지 고정이다.
  **v1/이전 v2 핀과 다르므로 ISE에서 반드시 이 UCF로 다시 피팅해 JED를 만든다.**
- EXTSLT와 데이터 출력은 푸시풀이다(로컬 버스).

시뮬레이션: `iverilog -o sim sim_top.v EXT_SLT_BUF.v && vvp sim` → `PASS: all checks`
(리셋값, FFFFh 쓰기/보수 읽기, 페이지별 서브슬롯 선택, 다른 슬롯 쓰기 무시, BUSDIR 방향 제어를 검사한다.)

## 4. 전원

- JP5 1-2: 슬롯 및 로직 VCC = 본체 +5V (INT)
- JP5 2-3: VCC = DC잭(5.5/2.1, 센터+, 5V) + 릴레이 K1. K1 코일은 본체 +5V로 구동하므로 본체가 꺼지면 외부전원도 끊긴다(v1과 같은 개념).
- ±12V, SOUNDIN은 본체에서 그대로 전달한다. 슬롯별 SOUND는 JP1–4, JP6–7(2핀 헤더 + 점퍼 캡, 기본 장착)의 캡을 빼서 분리할 수 있다.
  헤더는 각 슬롯 위쪽, 기판 위 가장자리 근처(카트리지 밖)에 있다(1번 핀 = 슬롯 SOUND, 2번 핀 = SOUNDIN).
- 사운드 출력(J10, 3.5mm, 왼쪽 가장자리 J1 위쪽, 왼쪽을 향함): 각 슬롯 SOUND(점퍼의 슬롯 쪽)를 2.2kΩ(R2–R7)으로 한 점에 모아
  10µF(C13)로 직류를 막고 47kΩ(R8)로 GND에 내린 뒤 잭의 L/R에 같이 낸다(모노). 증폭이 없는 라인 레벨이므로
  앰프 달린 스피커나 믹서 라인 입력에 연결한다. 본체 SOUNDIN이 연결되지 않은 기종(대우 등 한국형 MSX로 알려짐)에서
  확장 슬롯의 사운드 카트리지 소리를 듣는 용도다.
  - 점퍼 캡을 끼운 슬롯끼리는 SOUNDIN 선으로 서로 직결되므로, 사운드 카트리지를 둘 이상 쓰면서 잭으로만 들을 때는
    해당 슬롯 점퍼를 빼는 것이 좋다(출력끼리 맞물리지 않고 2.2kΩ로만 섞인다).
- 3.3V: AP2112K-3.3 (CPLD 전용)
- 권장: VCC 경로에 1A 폴리퓨즈 추가. 버퍼가 생기면서 v1보다 보드 소비전류가 수십 mA 늘어난다.

## 6. KiCad 회로도 (hardware/kicad/)

- `adapter/adapter.kicad_sch`: 어댑터
- `expander/expander.kicad_sch`: 확장 보드 (CPLD 심볼은 프로젝트 라이브러리 `MSXExp.kicad_sym`)
- `gen_schematics.py`: 위 두 회로도를 만드는 생성 스크립트. 결선을 바꿀 때는 이 스크립트를 고친 뒤 다시 생성한다.

회로도는 **결선(넷리스트) 정의용**이다. 핀마다 짧은 스텁과 넷 라벨로 연결되어 있다.
KiCad 8에서 ERC 위반 0건과 넷리스트를 확인했다.

```
python3 hardware/kicad/gen_schematics.py
kicad-cli sch erc hardware/kicad/expander/expander.kicad_sch
```

### 어댑터 PCB (`adapter/adapter.kicad_pcb`)
`gen_adapter_pcb.py`로 생성한다(배치, 배선, GND 면, 거버 출력까지 스크립트가 처리하며 오토라우터는 쓰지 않는다).

```
python3 hardware/kicad/gen_schematics.py
python3 hardware/kicad/gen_adapter_pcb.py      # → adapter/adapter.kicad_pcb, adapter/fab/, adapter/adapter_fab.zip
kicad-cli pcb drc --schematic-parity hardware/kicad/adapter/adapter.kicad_pcb
```

- 외형, 금도금 핑거, 케이스 보스 구멍 2개(H1 (103.062, 66.718), H2 (46.862, 61.318), 지름 4.36mm)는
  msx_v9990 카트리지 PCB와 같다. 같은 코나미형 쉘 케이스를 쓸 수 있다.
- 핑거 풋프린트 `MSXExp:MSX_CardEdge_50P_P2.54mm`는 `hardware/kicad/MSXExp.pretty/`에 있다.
  홀수 핀은 B.Cu, 짝수 핀은 F.Cu(라벨면)에 있고, 앞면에서 볼 때 1/2번 핀이 오른쪽이다. 44번(SW1)은 1mm 짧다.
- J2는 2×25 **직각(90°) 박스헤더**(`IDC-Header_2x25_P2.54mm_Horizontal`)이다. **하면(B면)** 에 실장하며,
  삽입구가 보드 윗변보다 4.0mm 바깥으로 나와 카트리지 윗면에서 보인다(`J2_OVERHANG`으로 조정).
  1번 핀이 오른쪽이고, 홀수 줄(+5V 45/47 포함)이 핑거 쪽 아래 줄, 짝수 줄이 윗변 쪽 위 줄이다.
  헤더는 보드 가로 중앙(x = 70.147mm)에 두었다. 핑거 중심(75.202mm)보다 5.06mm 왼쪽이며, 배선은 팬아웃 구간에서 이 차이를 흡수한다.
- 아래 줄 GND 핀(41, 43)은 신호선에 둘러싸여 있으므로 B.Cu에서 패드 사이로 빠져 헤더 몸체 아래 GND 면에 연결한다.
  상면에 실장하면 1번 핀이 왼쪽으로 가서 배선이 전부 교차하므로 하면 실장으로 했다.
- 배선은 두 구멍 사이를 2.0mm 피치로 좁혀 지나간 뒤 헤더 피치로 다시 벌어진다.
- 양면 GND 면을 깔고 스티칭 비아를 넣었다. 텅(핑거부)에는 동박 면과 비아가 없다.
- 발주 시: 1.6mm, 금도금 핑거(ENIG/Hard gold), 45° 베벨.

### 확장 보드 PCB (`expander/expander.kicad_pcb`)
`gen_expander_pcb.py`로 생성한다. 슬롯 버스·전원 일부는 스크립트가 직접 그리고, 나머지는 Freerouting으로 자동 배선한다.

```
python3 hardware/kicad/gen_schematics.py
python3 hardware/kicad/gen_expander_pcb.py      # 배치 → 자동배선 → GND 면 → 거버 (수십 분 걸림)
kicad-cli pcb drc --schematic-parity hardware/kicad/expander/expander.kicad_pcb
```

- 2층, 직사각형 206 × 124.5mm. 카트리지가 커넥터보다 길어서, 슬롯 커넥터 몸체에서 위 가장자리까지 약 25mm,
  아래 가장자리까지 약 15.7mm를 두었다. 배치 확인용 1:1 PDF: `hardware/kicad/expander/expander_placement_1to1.pdf`.
  M3 구멍 4개(오른쪽 아래는 DC잭 자리라 위로 올렸다).
- 슬롯 커넥터(J4–J9)는 세로 방향이다. 1/2번 핀이 아래, 짝수 핀이 왼쪽 열이다(v1과 같은 방향).
  간격은 22mm이고, 슬롯 3과 슬롯 4 사이만 27mm이다. 풋프린트 `MSXExp:MSX_Slot_AMP5530843`은
  v1 드릴 데이터 기준이다(핀 2열 간격 5.08mm, 핀 구멍 1.0mm, 고정 구멍 3.5mm 2개, 간격 78.11mm).
- J1은 직각 IDC로 왼쪽 가장자리에 붙는다. 핀 줄이 슬롯 핀 줄과 같은 높이이고, **홀수 줄(+5V 45/47)이 삽입구(케이블) 쪽**이다.
  풋프린트 `MSXExp:IDC-Header_2x25_P2.54mm_Horizontal_OddRowFront`은 KiCad 표준 직각 IDC에서 두 줄을 맞바꾼 것이다.
  **어댑터에 쓴 표준 부품(홀수 줄이 삽입구에서 먼 쪽)과 반대 구조이므로, 1번 핀이 삽입구 쪽 줄인 부품을 골라야 한다.**
- 슬롯 버스: 같은 번호 핀끼리 핀 줄 사이 틈(2.54mm)을 지나는 수평 배선으로 6개 슬롯을 잇는다(틈마다 층별 1가닥, 신호 0.3mm, 전원 0.4mm).
  슬롯별 신호(/SLTSL, /BUSDIR, SOUND)는 버스와 겹치지 않는 통로로 위·아래로 빠진다.
- 왼쪽: J1 → 버퍼(U2, U5, U1, U3, U4 순) → 버스. 오른쪽: 버스 끝이 CPLD(U7)로 바로 들어가고, CPLD 아래에 전원부(K1, JP5, C3)가 있다.
  DC잭 J2는 오른쪽 아래 모서리에서 오른쪽을 향하고, JTAG(J3)는 CPLD 위쪽에 있다.
- 슬롯 스위치 SW1–4는 직각 슬라이드 스위치로, 각 슬롯 아래 기판 가장자리(커넥터 몸체에서 약 15mm)에 있다. 손잡이가 기판 밖으로 약 4mm 나온다.
- 버스 아래 틈: RN3/RN4는 슬롯 3–4 사이, U6/C9는 슬롯 4–5 사이, RN5는 슬롯 5 오른쪽에 있다.
- GND는 자동 배선하지 않고 양면 GND 면과 스티칭 비아로 연결한다. SMD GND 패드에는 고정 비아를 두었다.
